# Changelog — Telegram Tag Distribution Manager (TG Tag Manager PRO)

## [Unreleased]
- Експорт поточної або відфільтрованої бази операторів у Excel/JSON.

## [1.2.0] - 2026-10-01
### Added
- Інтерактивний табличний редактор бази операторів (Edit Base) з окремими полями ID, Ім'я, Telegram-тег.
- Динамічне додавання (+ Додати) та видалення рядків операторів на льоту.
- Миттєвий пошук та фільтрація в модальному вікні за ID, ім'ям або тегом.
- Лічильник загальної кількості записів у базі (`dbTotalCounter`).
- Повна адаптивність під мобільні пристрої (iOS / Android), тач-таргети від 44px, захист від автозуму в iOS Safari (`font-size: 16px`).

### Changed
- Синхронізація локального сховища `localStorage` (`opsDB` та `operator_db`).
- Автоматична валідація та нормалізація префікса `@` при збереженні та імпорті.

## [1.1.0] - 2026-10-01
### Added
- Вхідна точка `index.html` для коректного деплою на GitHub Pages.
- Інтеграція SheetJS (`xlsx.mini.min.js`) для імпорту баз клієнт-сайд.
- Zero-Leak верифікація: виключення конфіденційних файлів через `.gitignore`.

### Changed
- `DEFAULT_DB` очищено для безпечного публічного коду.
- Логіка зберігання перенесена в `localStorage`.

## [1.0.0] - Initial Architecture
- Базовий функціонал парсингу ID операторів.
- Клієнтська розмітка `index2.html` та скрипт `script2.js`.
