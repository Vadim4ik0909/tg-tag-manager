# Changelog — Telegram Tag Distribution Manager (TG Tag Manager PRO)

## [1.4.8] - 2026-10-04
### Added
- Власні поля вводу тривалості перерви (хвилини + секунди) у спливаючому меню (`.break-custom-row`):
  - Можливість запуску довільного таймера в хвилинах і секундах за допомогою кнопки `▶`.
  - Швидкі пресети на 15 хв, 30 хв та 1 год (Обід).
  - Анімоване кільце прогресу та посекундний таймер для кастомних перерв.
### Fixed
- Позиціонування випадаючого меню перерви: відступ та закріплення суворо під іконкою виклику.

## [1.4.7] - 2026-10-04
### Added
- Анімований радіальний круговий таймер (SVG circular progress ring) для перерв та обіду:
  - Візуальне плавне вичерпання кільця прогресу з плином часу.
  - Точний зворотний відлік у реальному часі у форматі `(залишилось MM:SS • до HH:MM)`.
  - Миттєве повернення оператора до активних при кліку на бейдж або після закінчення часу з м'яким зеленим спалахом.
### Fixed
- Рефакторинг макета картки оператора (`.card`):
  - Верхній рядок: тільки чекбокс, ID та повне ім'я оператора без зайвих кнопок дій.
  - Нижній рядок (`.card-footer-row`): зліва Telegram-тег, справа кнопки дій (`.card-footer-actions`).
  - Абсолютне позиціонування випадаючого меню перерви безпосередньо під іконкою виклику (`.break-trigger-wrap`).

## [1.4.6] - 2026-10-04
### Added
- Система таймерів перерв та обіду для операторів (15 хв, 30 хв, 1 год / Обід):
  - Кнопка швидкого виклику меню перерви (`☕️ .btn-break-trigger`) у шапці картки.
  - Збереження стану перерв у `localStorage` (`tg_breaks_state`).
  - Фоновий таймер з автоматичним оновленням залишку хвилин на бейджі (`☕️ 15 хв (11 хв)` / `🍔 Обід (48 хв)`).
  - Автоматичне виключення оператора з розрахунку та автоматичне повернення до списку після закінчення часу або при кліку на бейдж.
### Fixed
- Оптимізація та розвантаження шапки картки:
  - Повернення до компактного циклічного перемикача форс-мажорів (`⚡️`, `🌐`, `⏸`).
  - Забезпечення повного горизонтального простору для відображення імен та тегів операторів без обрізання.

## [1.4.5] - 2026-10-04
### Added
- Інтерактивна кнопка-корона (👑 `.btn-lead-toggle`) на кожній картці оператора для призначення або зняття статусу «Головний бази»:
  - Швидке перемикання Головного в один клік безпосередньо з інтерфейсу.
  - Правило єдиного активного Головного бази: призначення нового автоматично знімає статус із попереднього.
  - Автоматичне вимкнення чекбокса для виключення Головного з калькулятора заявок та результуючого списку тегів.

## [1.4.4] - 2026-10-04
### Added
- Мікро-панель керування статусом із 3 прямими іконками (`⚡️`, `🌐`, `⏸`) на кожній картці оператора (`.card-status-bar`):
  - Миттєве призначення потрібного статусу або скидання у звичайний стан в один клік.
  - Візуальне підсвічування активної кнопки статусу відповідним фірмовим відтінком.
  - Автоматична синхронізація активності чекбокса та перерахунку заявок і тегів.

## [1.4.3] - 2026-10-04
### Added
- Підтримка статусів форс-мажорів та відсутності зв'язку (No Light, No Internet, Offline):
  - Автоматичний текстовий парсинг суфіксів у списку:
    - Без світла: `47(б/с)`, `47(без світла)`, `47(світло)` тощо.
    - Без інтернету: `105(б/і)`, `105(без нету)`, `105(нет)`, `105(інет)`, `105(інтернет)` тощо.
    - Офлайн: `73(офлайн)`, `73(off)`, `73(немає)` тощо.
  - Автоматичне зняття чекбокса за замовчуванням (виключення з розрахунку кількості та генерації тегів).
  - Інтерактивні кольорові бейджі: `⚡️ Без світла`, `🌐 Без інтернету`, `⏸ Офлайн`.
  - Кнопка швидкого ручного перемикання статусу форс-мажору на кожній картці оператора в один клік.

## [1.4.2] - 2026-10-04
### Added
- Парсинг та підтримка операторів зі статусом Головного бази («(г)» / «(g)»):
  - Автоматичне маркування бейджем `👑 Головний (без заявок)`.
  - За замовчуванням чекбокс знято, щоб не враховувати головного в розрахунок заявок та видачу тегів (можна ввімкнути вручну).
- Парсинг операторів з обмеженим часом зміни («(до HH)» / «(до HH:MM)»):
  - Динамічне порівняння з поточним системним часом.
  - Закінчена зміна: бейдж `⏳ Зміна закінчилась`, приглушена прозорість картки, чекбокс знято за замовчуванням.
  - Скоро кінець зміни (менше 45 хв): пульсуючий бейдж `⚠️ Скоро кінець зміни`, м'яка бурштинова рамка картки.
  - Активна зміна: інформаційний бейдж `🕒 До HH:MM`.

### Security
- Політика Zero-Leak: `DEFAULT_DB = {}` залишається строго порожнім у репозиторії.
- Файл `opsDB_backup.json` надійно ігнорується у `.gitignore`.
- Strict Push Policy: всі коміти залишаються строго локальними.

## [1.2.8] - 2026-10-01

- Автоматична санітизація імен операторів у `loadDB()`: шаблони `Оп {id}`, `Оп #{id}` або `#{id}` очищаються в порожній рядок `""`.

- Покращено адаптивну поведінку `.card-title` та `.card-name` при довгих іменах.

### Security
- Політика Zero-Leak: `DEFAULT_DB = {}` залишається порожнім.
- Strict Push Policy: всі коміти залишаються строго локальними до явного тригера "пуш" / "push".
